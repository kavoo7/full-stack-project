# Jupiter School Admin System - Frontend Client

This directory contains the React 19 + Vite frontend single-page application for the Jupiter School Admin System.

## Main Documentation

For full project details, setup guide, architecture, and API documentation, please refer to the [Root README](../../README.md).

## Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
